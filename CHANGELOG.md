# 📋 История изменений (Changelog)

## [1.0.4] — 2026-09-14

### 🚀 Новые функции (New Features)
- **Множественное скачивание (Batch Download)**:
  - Добавлен режим пакетной загрузки списка ссылок на главной странице с переключателем.
  - Большое текстовое поле с поддержкой построчного ввода ссылок любого формата (`link.com`, `link2.com`, `https://...`).
  - Умная авто-нормализация: автоматическое добавление схемы `https://` для доменов без протокола.
  - Динамический счётчик распознанных ссылок с поддержкой русской и английской грамматики.
  - Быстрые кнопки вставки из буфера обмена («Вставить из буфера») и быстрой очистки («Очистить»).
  - Пакетные настройки: одновременный выбор формата (MP4 / MP3), качества (до 4K), кодека (H.264, AV1, Auto), битрейта аудио и субтитров для всех ссылок разом.
  - Атомарное добавление всех задач в очередь скачивания (`download:batch`) с моментальным переходом на вкладку «Загрузки».
  - Автоматическое извлечение реальных названий видео из выходных путей `yt-dlp` для задач, добавленных без предварительного анализа.

### 🎨 Улучшения интерфейса и UX (UI & UX Improvements)
- **Плавный переключатель режимов (Animated Segmented Switch)**:
  - Фоновый индикатор (`add-mode-indicator`) плавно скользит между вкладками «Одиночная ссылка» и «Множественный ввод» за 0.25с.
  - Мягкая анимация появления (`slide-fade`) при смене режимов ввода без скачков по высоте и ширине.
- **Оптимизация CustomSelect**:
  - Адаптивная 2-колоночная сетка параметров (`batch-config-grid`) с достаточной шириной колонок (220–320px).
  - Снято ограничение ширины выпадающего меню (`width: max-content; max-width: 380px`), длинные названия опций больше не обрезаются.
  - Интеллектуальное выравнивание выпадающих списков по правому краю у границ экрана (`align-right`).
  - Добавлен атрибут `title` для подсказок полного текста при наведении курсора.
  - Оптимизированы и сокращены формулировки названий видеокодеков.
